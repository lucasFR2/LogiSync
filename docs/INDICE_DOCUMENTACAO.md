## 🎓 GLOSSÁRIO

- **CRUD**: Create, Read, Update, Delete (Criar, Ler, Atualizar, Deletar)
- **SKU**: Código único do produto
- **Migration**: Script que cria tabelas no banco
- **View**: Template HTML (arquivo .blade.php)
- **Controller**: Lógica da aplicação
- **Model**: Representação dos dados
- **Route**: Enderço/URL do site
